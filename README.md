# Ola Bookings Analysis | Power BI

## 📌 Overview

An interactive **Power BI dashboard** built to analyze Ola booking data and understand **booking performance, revenue, vehicle types, cancellations, and customer/driver ratings**.

The dashboard provides a business-focused view of ride-booking performance and helps identify key trends and operational insights.

## 🎯 Objectives

* Analyze overall booking performance.
* Understand revenue and ride trends.
* Compare performance across vehicle types.
* Analyze customer and driver cancellations.
* Evaluate customer and driver ratings.
* Identify key business trends and performance areas.

## 📊 Dashboard Pages

### 1. Overall

* Booking status analysis
* Total customers
* Total booking value
* Booking trends over time

### 2. Vehicle Type

* Booking value by vehicle type
* Ride distance analysis
* Vehicle-wise performance comparison
* Booking and revenue metrics

### 3. Revenue

* Revenue analysis by time period
* Booking value trends
* Revenue performance analysis
* Detailed revenue breakdown

### 4. Cancellation

* Customer cancellation analysis
* Driver cancellation analysis
* Cancellation percentage
* Booking and revenue impact

### 5. Ratings

* Customer ratings
* Driver ratings
* Rating comparison across vehicle types
* Rating performance analysis
